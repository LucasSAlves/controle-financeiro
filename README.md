# Sistema de Controle Financeiro

Sistema de controle financeiro pessoal desenvolvido para organizar entradas, despesas, categorias, formas de pagamento e vencimentos.

## Tecnologias utilizadas

* Laravel
* React
* Inertia.js
* Tailwind CSS
* MySQL

## Funcionalidades

* Cadastro e autenticação de usuários
* Cadastro de entradas e despesas
* Controle de movimentações parceladas
* Categorias personalizadas
* Formas de pagamento
* Filtros por mês, tipo e status
* Dashboard financeiro
* Marcação de despesas como pagas
* Avisos de vencimento por e-mail

## Ambiente de produção

O sistema está publicado em:

`https://controlefinanceirosilva.space`

## Instalação local

As configurações privadas foram inseridas no arquivo `.env`.
